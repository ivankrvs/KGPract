Как работают алгоритмы

Средняя точка. Для концов отрезка вычисляются 4-битные коды положения относительно окна. Если оба кода нулевые — отрезок виден целиком; если побитовое «И» кодов ≠ 0 — отрезок целиком снаружи; иначе он делится пополам в средней точке, и алгоритм рекурсивно применяется к каждой половине. Деление прекращается, когда длина части ≤ ε. Умножений и делений нет, только сложение и деление на 2, а число шагов порядка log₂(L/ε).

Кирус — Бек. Отрезок задаётся параметрически: P(t) = A + t·D, t ∈ [0; 1]. Для каждого ребра выпуклого многоугольника (обход против часовой стрелки) берётся внутренняя нормаль n; точка внутри, если n·(P(t) − Pᵢ) ≥ 0, то есть num + t·den ≥ 0, где num = n·(A − Pᵢ), den = n·D. При den > 0 это «вход» (t ≥ −num/den, обновляется tE = max), при den < 0 — «выход» (tL = min), при den = 0 отрезок параллелен ребру и виден только если num ≥ 0. Если tE ≤ tL, видима часть от P(tE) до P(tL).
