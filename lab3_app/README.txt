Лабораторная работа 3. Базовые растровые алгоритмы
Пошаговый алгоритм, ЦДА, Брезенхем (отрезок), Брезенхем (окружность), сглаженная линия (Ву).

Запуск приложения
1. Распакуйте архив.
2. Откройте index.html двойным кликом (Chrome, Edge, Firefox). Установка и интернет не нужны.
3. Выберите алгоритм, введите координаты, нажмите «Построить». Масштаб — ползунок или авто.
   Под рисунком — таблица расчёта по шагам; кнопки «Замерить» — время работы.

Содержимое
index.html     — приложение (HTML + CSS + JavaScript в одном файле)
src/algos.js   — реализации алгоритмов и функция замера времени (тот же код, что в index.html)
src/all.js     — автотесты корректности и замеры времени (запуск: node src/all.js; нужен Node.js)
