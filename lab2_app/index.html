Реализованные методы и формулы

Все поэлементные операции заданы таблицей замены out = f(in) для 256 уровней и применяются к каждому каналу R, G, B.

Сложение: f(v)=v+c. Умножение: f(v)=k·v. Негатив: f(v)=255−v. Гамма: f(v)=255·(v/255)^γ (γ<1 осветляет тени, γ>1 затемняет). Логарифм: f(v)=255·ln(1+v)/ln(256), раскрывает тёмные области. Результат всегда ограничивается диапазоном [0,255].

Линейное контрастирование: f(v)=255·(v−lo)/(hi−lo). Границы lo и hi — минимальная и максимальная яркость; при «Отсечении» p % берутся перцентили p и 100−p. Так одиночные выбросы не мешают растяжению диапазона.

Метод Оцу выбирает порог T, который максимизирует межклассовую дисперсию σ²(T)=ω₀ω₁(μ₀−μ₁)². Метод треугольника проводит прямую от пика гистограммы к дальнему концу её «хвоста» и берёт точку гистограммы с максимальным расстоянием до этой прямой. Перед этим гистограмма сглаживается.

Выводы по сравнению (проверьте на тестовых изображениях)

Контрастирование. На «Малоконтрастном» и «Тёмном» изображениях линейное растяжение раскрывает весь диапазон, а гистограмма «растягивается» без изменения формы. Сложение лишь сдвигает гистограмму, не меняя разброс, а умножение растягивает её от нуля и может обрезать светлые значения. Если на изображении есть шумовые выбросы, при отсечении 0 % растяжение почти не меняет картинку, а при 1–2 % результат заметно лучше.

Пороги. На «Объекты на фоне (два пика)» гистограмма бимодальна, Оцу даёт чёткую границу, а фиксированный T=128 на «Тёмном» изображении теряет объекты. Треугольник лучше подходит для «Мелкие объекты на большом фоне»: гистограмма там унимодальна, один пик фона доминирует. Оцу склонен отрезать часть фона, когда классы очень разного размера. На «Неравномерном освещении» все глобальные методы ошибаются: один порог не подходит для светлой и тёмной частей, нужна локальная обработка.

Подборка изображений

Тестовые изображения генерируются в приложении: объекты на фоне (два пика) — лучший случай для Оцу; малоконтрастное и малоконтрастное с выбросами — для линейного контрастирования (с выбросами при отсечении 0 % растяжение почти не работает, при 1 % работает); тёмное — для контраста, гаммы и сравнения с фиксированным порогом; мелкие объекты на большом фоне — Оцу хуже, треугольник лучше; неравномерное освещение — глобальные методы не справляются.
