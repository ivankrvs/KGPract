Лабораторная работа 2, вариант 6
Поэлементные операции + линейное контрастирование; глобальная пороговая обработка (Оцу, треугольник)

Как запустить
1. Распакуйте архив.
2. Откройте файл index.html двойным кликом (Chrome, Edge, Firefox). Установка и интернет не нужны.
   Всё работает локально: код — один файл index.html (HTML + CSS + JavaScript).
3. Вверху выберите тестовое изображение или загрузите своё («или свой файл»).
   Вкладка 1 — поэлементные операции и линейное контрастирование; вкладка 2 — пороговая обработка.

Содержимое
index.html     — приложение
test_images/   — база тестовых изображений (PNG 256x256): bi (два пика), low (малоконтрастное),
                 outl (малоконтрастное с выбросами), dark (тёмное), small (мелкие объекты), uneven (неравномерное освещение).
                 Эти же изображения генерируются внутри приложения; файлы можно загружать кнопкой выбора файла.
